# AutoTyper  
## A Tool to Make Programming Lectures Interactive & Effective  

---

## 1. Abstract  
AutoTyper is a desktop-based tool designed to improve the way programming is taught in classrooms. It simulates real human typing inside any code editor, allowing teachers to present code step-by-step in a natural and controlled manner.  

Unlike traditional methods, AutoTyper types code character by character with real cursor movement, helping students understand logic, syntax, and structure more effectively. It reduces typing errors, saves time, and makes lectures more interactive and engaging.  

---

## 2. Problem Statement  

In most programming classes, students only see the final code instead of how it is built step-by-step.  

### A typical classroom situation:
- The teacher starts typing code  
- Students try to follow but fall behind  
- Small typing mistakes waste time  
- To save time, the teacher pastes full code  

### As a result:
- Students don’t understand how the code is built  
- They struggle with logic and structure  
- Learning becomes passive  

### Key Insight:
👉 Students don’t struggle with code — they struggle with how the code is built.  

---

## 3. Objective  

- Improve programming teaching methods  
- Make lectures more interactive  
- Help students understand step-by-step code development  
- Reduce manual typing effort  
- Increase student engagement and retention  

---

## 4. Proposed Solution: AutoTyper  

AutoTyper is a tool that simulates real human typing inside any editor.  

Instead of instantly showing full code or even full lines, AutoTyper:  

- Types letter by letter  
- Moves the cursor naturally  
- Handles indentation and spacing automatically  
- Creates a real-time coding experience  

All of this is controlled using a single key (**F8**).  

👉 AutoTyper doesn’t just display code — it recreates the real coding process.  

---

## 5. Key Features  

- Paste any programming code  
- Automatically split code into lines  
- Edit, reorder, or delete lines  
- Save projects as reusable files (`.pds`)  
- Simulates real typing (character-by-character, not instant paste)  
- Automatic cursor movement and indentation  

### One-key control (F8):
- Press F8 → Start typing  
- Do not press F8 → No typing (full control to teacher)  

---

## 6. Working of the System  

1. Paste your code into AutoTyper  
2. Click “Next” to split into lines  
3. Edit or arrange lines as per teaching flow  
4. Save the project  

### During lecture:
- Press F8 → AutoTyper starts typing  
- Code appears character by character  
- Cursor moves like real programming  

👉 If the teacher wants to pause or explain:  
- Simply don’t press F8 again  
- Teaching remains fully under control  

---

## 7. Real-World Use Case  

A teacher wants to explain a function:  

- First shows the function structure  
- Pauses to explain  
- Then uses AutoTyper  

AutoTyper types the code:  

- Character by character  
- With real cursor movement  
- At a controlled speed  

Students feel like the teacher is actually writing code live and can clearly understand how it is built step-by-step.
